# XAU Sinyal by Aryansyah

*Trade What You See, Not What You Hope*

Aplikasi Android pemberi notifikasi peluang entry **XAUUSD** (emas) berdasarkan:
1. Support & resisten (swing 15m)
2. Korelasi dolar (EUR/USD sebagai kebalikan DXY)
3. Order book FastBull (antrean order & posisi retail)

plus Stochastic 5,3,3 dan filter tren 15m.

## Unduh

**[⬇ Unduh APK terbaru](https://github.com/aryansyah277-cmd/xau-sinyal/releases/latest/download/XAU-Sinyal.apk)** — Android 8 ke atas.

## Cara pakai
1. Instal APK, izinkan notifikasi.
2. Buat API key gratis di [twelvedata.com](https://twelvedata.com) lalu isi di tab **Pengaturan**.
3. Tekan **Cek sekarang** untuk analisa, atau **Mulai memantau** agar notifikasi masuk otomatis tiap 5 menit.

## Penting
Sinyal adalah hasil aturan analisa otomatis — **bukan jaminan profit dan bukan saran keuangan**. Selalu pasang stop loss, gunakan lot kecil, dan cek ulang chart sebelum entry. Data order book diambil dari halaman publik FastBull dan bisa berhenti bekerja sewaktu-waktu.
